# 0.5.0进度

以下为已写入的原型规则，尚待战役验收，数值可以调整。

| 系统 | 规则 |
|---|---|
| 建站 | 每年最多一个；100合金、50影响力、100能量；相邻、已勘测、无主且无敌舰 |
| 殖民 | 每年最多一团；200合金、800矿物、300食物、200消费品、200能量；适居至少60%；一年后复核归属再落地 |
| 工程包 | 孵化场和反应釜；白蚊人开拓，灰蚊人经正常队列补缺 |
| 组织度 | 初始80，每年+5，建站-4、殖民-6；首都整编花费500凝聚力与500能量，+25，冷却五年 |
| 神殿 | 暂按全帝国任一有效神殿停止新任务、每年额外+5；在途殖民继续 |
| 分裂 | 连续两年低于20；只选成熟五年的自动殖民地；保护母星、首都、手动殖民及多殖民地星系；最多三个，间隔十年 |
| 双飞升 | 王家双螺旋后基因与灵能并行；保留其他帝国及合成／义体互斥条件 |
| 蓝图 | 舰团化及对应轴炮／舰体科技解锁后注册三档生产蓝图；没有赠船或赠送玩家资源 |

友好子势力继承科技和白灰制度，建立通讯、友好关系、停战；不复制母星资源礼物。

中期在玩家相邻无主适居世界建立独立白蚊人＋机器人国家；没有位置则延后，不抢其他文明领土。援助实际转移3000食物，五年后回报十年贸易+25%及2000凝聚力。拒绝后六个月出现“饿殍遍地”，两年后进入钢铁动员。

动员选择原版合成飞升及合成传统，启动对应DLC的原版局势／项目，没有伪造飞升完成。敌方一次获得机器人劳动力、物资、24重舰和24轻舰，分为四舰团，二十年工业加成。这些是待调校的事件难度，不发给玩家。五年整备后，在独立、和平且无停战时宣战，符合条件的子势力加入；目标为羞辱，不直接转移母星。没有灰蚊人集体机械化。

人口406组／19200月度步骤、边疆控制流22组、两条借粮分支和双飞升24组检查通过。依赖检查覆盖科技、建筑、区划、船段、插槽、蓝图与事件引用。

首轮真实引擎读到0.5.0定义，发现并修正本地化函数、关系衰减、修正名称、工业区划及宏转义错误。双飞升重复定义提示来自有意的本机覆盖，原版副本不分发。修订版仍待引擎复查；合成项目AI完成、联军、实际战力和长期性能尚未验收。

银心开局和动态嘴部仍待制作。舰体以用户的长枪D／捕网三视图为准，加载、尺度、炮口、推进器与运动需单独验收。

新局自动存档（2203.07.01）确认灰蚊人已脱离Serviles模板并实际承担专家岗位，但仍有700闲置灰蚊人；删除数量表达式未达到预期，已改为原版虚拟人口的kill_pop_group接口，待重载后复测。白蚊人保留，不用迁移替代删除。

已接入三种原创框架、六舰段和三张自制DDS，含炮口／推进器节点及可编辑OBJ。炮塔当前为固定几何，关闭原版炮塔叠加。实机显示与开火待验收。
