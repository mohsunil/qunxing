# 人口原型游戏内验收

状态：以下项目尚未执行。使用新建非铁人测试存档，不用于已有战役。正式游玩不需要控制台；开发时可用控制台缩短等待，但结果应以普通经济条件重新复核。

1. 原版基线：在同一安装版本中不启用任何 Mod，确认能进入主菜单并创建新局。
2. 仅启用海帕姆原型：在预设列表选择“海帕姆帝国（初航原型）”；确认起源仍显示协同进化、两种族名称正确、初始白蚊人与灰蚊人存在。
3. 初始化：经过3天确认原型提示出现，母星两栋测试建筑与资源地貌存在；灰蚊人不再携带 Serviles，能就职专家岗位。
4. 领袖：核对统治者、已任领袖、招募池、研究及舰队指挥官均为白蚊人；测试招聘与事件加入领袖。确认其他普通帝国仍能生成自身领袖。
5. 工人缺口：完成一项新增工人岗位的建设，记录完工日与缺口劳动力；在3—6个月内由灰蚊人补齐。记录出生数与实际就职数，不能只看总人口上涨。
6. 专家缺口：分别测试合金、消费品、科研、医疗与士兵的非精英岗位。确认灰蚊人可以进入，无权限导致的反复孵化与删除。
7. 连续扩建：第一批尚未完成时增加第二批岗位，确认第一批按原进度到达，第二批单独排队。
8. 关闭岗位：在出生前关闭部分/全部岗位，确认取消对应批次；出生后关闭岗位，确认只移除闲置灰蚊人数量，不删仍就职的灰蚊人，也不删白蚊人。重点检查部分人口组闲置时的行为。
9. 停用建筑与满员：停用、拆除、恢复孵化场；停止自然与额外组装增长；满员至少运行两年，确认没有持续增长、失业积累或负数队列。
10. 反应釜：对同星球灰蚊人记录食物维护，停用/恢复反应釜比较；白蚊人不应获得同一专属减耗。创建灰蚊人基因模板并应用，确认谱系、就业、出生和减耗仍有效。
11. 殖民地与转手：新殖民地建设孵化场；测试无本地灰人口时的首次孵化、星球易主与原主人失去所有灰人口后的事件安全性。
12. 存读档：出生前、队列缩减后与建筑停用时各存读一次，确认队列无重复完成、延误或重新计时。

每轮保留游戏版本、启用模组列表、日期、相关存档、关键截图与筛选后的脚本错误。不向公开仓库上传Steam身份、整份个人日志或原版资源。全部通过前，`in_game_tests_passed` 保持 `false`。
