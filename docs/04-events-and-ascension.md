# 边疆、饥荒与钢铁蚊人事件链

全部为本Mod的用户创作方向，不代表已核实的逐鹿银河官方历史。

## 主链

研究舰团化 + 无重力子神殿 → 边疆向无主区自动扩展 → 部分可居住星球自动殖民 → 组织度低时友好分裂 → 中期独立势力借粮 → 拒绝 → 饿殍遍地 → 机器人与机械飞升推动实力爆发 → 联合其他子势力开战。

用户原话“自动致命”按语境整理为“自动殖民”；未将其解读为星球死亡。

## 边疆扩张

无神殿暂按帝国内没有任何有效重力子神殿解释，但该范围未获用户单独确认。新建神殿后是否停止新拓殖、是否提升组织度，也未定案。

自动扩展仍需设计资源支付、适居条件、扩展距离、频率、星路可达性和势力归属。组织度建议独立于原版稳定度，阈值与恢复方式未定。友好分裂初始不应直接变成敌对叛乱。

## 中期借粮

独立白蚊人与机器人国家向玩家求粮。用户尚未确定这个国家必须来自此前分裂，还是允许独立预设国家；优先选已有国家属于助手建议。

拒绝后出现饿殍遍地通讯。是否存在第二次救援机会、借粮数量、贷款返还、事件间隔和援助成功分支均未定。

## 饿殍遍地

事件标题是用户明确要求。当前对白草稿位于events/hunger_dialogue_zh.txt，尚未得到用户逐句确认。

饥荒由粮食供应问题引起，不应重新引入灰蚊人失控繁殖。事件国家构成为白蚊人与机器人；不要错误使用海帕姆灰蚊人的供需人口机制解释其全部人口。

## 钢铁蚊人最新设定

初期文明由白蚊人与机器人组成，大规模使用机器人承担生产和军事，明确走机械／合成飞升。钢铁蚊人不是因灰蚊人集体转化而诞生。

机械飞升后的白蚊人合成化程度、身份和领袖谱系处理需跟具体路线定义。不能仅使用早期“机器人不吃饭”叙述就提前宣称所有白蚊人无需食物。

强度上升应表现为生产、自动化、机器人陆军、舰队装备与补充能力改善；敌方规模、出现阶段和难度适配需要实测。用户希望能靠海帕姆真实经济与海军正面迎战。

## 联合战争

钢铁蚊人联络其他子势力结盟并攻击玩家。成员选择、阵营外交、玩家是否能阻止加入、战争目标和战后处理尚未确定。

## 玩家海帕姆的双飞升

基因飞升和灵能飞升并行；皇家孵化场、快速灰蚊人改造对应基因方向；灵蚊人、重力子神殿、专属陆军与事件对应灵能方向。需要定制互斥条件、传统树、人口特质和局势，不能默认原版直接支持该组合。
