# 草案数值与未决事项

## 已有数字草案

以下全部由助手提出，用户未逐项确认，不是正式配置。

| 项目 | 对话中出现的草案 |
|---|---|
| 白／灰人口比例 | 白10%—20%，灰80%—90% |
| 灰蚊人基因改造 | 耗时减少90% |
| 舰团化单舰指挥上限 | 约常规50% |
| 舰团化海军容量 | +150% |
| 舰队维护 | 常规约25% |
| 同级海军占用 | 常规约50% |
| 轴炮基础持续伤害 | 同级约1.5—2倍 |
| 轴炮舰船体 | 同级约2倍 |
| 邮政贸易增益 | +50% |
| 邮政旧船事件 | 3—5年一次 |
| 反应釜食物减耗 | 初级50%，升级75% |
| 完工母星总船厂 | 60—100条并行线，约3倍常规造舰速度 |

用户明确锁定的精确时间是灰蚊人3—6个月补员；其他数字不能因本次打包被视为已批准。

## 实现前需确认或验证

- Stellaris版本、DLC、目标语言和安装路径。
- 首都类型、星球类型、初始人口、岗位和资源定量。
- 银心附近的定义与支持银河形状；不能无依据承诺任意地图精准定位。
- 灰蚊人从源头受控增长和岗位减少后的移除时点；孵化场失效时的余量处理。
- 自动移除是否只限玩家海帕姆，是否作用NPC海帕姆；食品赤字等特殊状态的处理。
- 白蚊人基因改造亚种、事件领袖与外部招募的身份规则。
- 灵蚊人来源、基因／灵能关系、人口规模及增长规则。
- 军耀殿是否替代首府主楼、寿命效果是否永久。
- 同级舰船低容量是否同时涉及指挥占用。
- 舰团化与重力子神殿的条件作用范围与状态变化。
- 钢铁蚊人的独立势力来源、借粮数量、援助分支和战争目标。
- 舰造世界母星地表与实际船坞的联动方式，以及需要的DLC。

不要在开始开发前一次性要求用户回答全部事项；先确认影响最小原型的游戏版本与人口规则细节，其他在对应阶段处理。
