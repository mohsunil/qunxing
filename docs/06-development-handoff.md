# 开发交接与验收

## 当前事实

原工作区为空。没有已实现的群星脚本、模型、贴图、可安装Mod或游戏测试。此次新增的是设计文档、结构化需求、对白草稿、来源索引、交接说明和打包校验脚本。

Tripo连接器曾实测返回no API key configured。Blender与游戏安装位置尚未确认。授权在本机或工具中完成，不要求用户把密钥发进聊天。AI模型生成、导出、游戏显示和实战表现是不同验收项。

## 第一里程碑：真实人口原型

1. 确认版本与DLC，读取该版本原版起源、特质、岗位与人口API。
2. 建立独立Mod目录，不覆盖游戏安装文件。
3. 实现白／灰双种族协同进化开局和白蚊人领袖限制。
4. 实现皇家孵化场3—6个月补齐非精英岗位。
5. 实现过剩灰蚊人自动移除，反应釜食物减耗。
6. 游戏中检查新岗位、关闭岗位、持续扩建、专家岗位、基因亚种、存读档与被占领情况。

## 第二里程碑：一艘实际可用轴炮舰

先完成一艘舰的模型、材质、炮口与引擎挂点，导出适配格式，验证舰船设计器显示、比例、移动、开火及升级。然后制作舰团化、容量占用、维护与三档轴炮。

## 后续顺序

皇家设计局／军耀殿 → 邮政贸易与旧船 → 基因与灵能双路线／神殿 → 边疆组织度与友好分裂 → 饥荒钢铁事件 → 母星舰造工程 → 大可汗与后期爆兵实测。

## 战力验收

固定版本、难度、科技成本、危机设置、中期年份、地图与DLC。正常开局经营至中期，测试独立对抗大可汗主力和后续会战；后期测试持续生产、补舰与维护收支。记录真实结果，不把纸面容量倍数当成战斗胜利。

## 云端开发

用户最初要求私有GitHub仓库，随后创建mohsunil/qunxing，并于2026-10-16明确授权上传到该公开仓库。GitHub上传不等于Codex Cloud环境发布。包内setup-codex.sh只运行交接内容校验，不是游戏安装或Mod构建。

云端可处理文档、脚本与资源配置；本机游戏测试仍需合法安装的群星。不要上传原版游戏大包或密钥。未获额外指令，不创建新聊天或自动向其他聊天派发任务。

## 可直接用于后续开发的任务说明

请先阅读本工程README、AGENTS与design/requirements.json。按最新人口规则实现海帕姆群星Mod的最小原型：协同进化双种族、全白蚊人领袖、皇家孵化场3—6个月补齐全部非精英岗位、过剩灰蚊人自动消失、反应釜减食物维护。先识别版本差异并报告真实游戏测试结果，再逐步加入舰团化、等离子轴炮和后续系统。所有助手数值仍是草案。
