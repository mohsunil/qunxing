# 0.3.0-alpha：原图肖像与六个月存档核对

## 视觉资源

0.3.0曾直接使用Q版立牌，用户明确要求替换为正常比例。0.3.1已撤换活动Q版肖像：以资料库正常比例的荣耀卫兵、长生军三视图为主要参考，通过内置image_gen制作成年半身肖像；保留白蚊人无翼骑士军官、灰蚊人单眼虫械头与四翼。原Q版图只作盔徽及头盔结构参考。

最终PNG在 `assets/portraits`，完整提示词在 `assets/generation-prompts.md`。透明DDS为575×380。帝国盔徽及国民理念、特质、两栋建筑共五个功能图标继续保留；旗标有128、256、24三种尺寸。两栋建筑图标已补至引擎实际要求的buildings贴图目录。

本版未覆盖原版肖像库。旧测试存档下次月度检查会更新肖像与旗帜，保留物种特质。需要重启加载新贴图；视觉效果尚待游戏内实测。

## 六个月测试的证据与限制

用户实际运行至六个月，报告没有明显异常。本机找到 `2200.07.01` 自动存档并只在本地核查；不上传存档、Steam身份或完整个人日志。

已核对：

- 初始化日志在 `2200.01.02` 记录 `HAIPAM_INIT_COMPLETE`，初航提示已由玩家确认。
- 母星存在皇家孵化场与反应釜，社会学产出包含孵化场的12点试验产出。
- 海帕姆拥有的13个领袖/候选记录均属于白蚊人谱系。
- 灰蚊人总数2400，记录的自然增长为0。
- 试验存档没有空余工人或专家岗位，各待孵化变量为0；这验证了当前满员状态未安排孵化，不能验证新岗位出现后的出生时间。

同时发现未完成的行为：

- 旧版只创建了移除Serviles的灰蚊人模板，却未将现有人口切换到该模板。存档中灰蚊人仍保留Serviles，不能从事专家岗位。
- 灰蚊人中800处于平民类别，尚未自动清除，不能将“六个月无明显异常”称为完整人口机制通过。
- 星系生成时有三条无主未开智人口读取owner的脚本报错。

本版修正：明确创建并应用去除Serviles的模板，以精确物种匹配保留各基因变体；月度检查可迁移已有alpha存档；灰人口组使用明确的 `pop_group_has_trait` 检查；为本地规则适配器增加owner存在判断。修正已写入代码和本机Mod，尚待载入原存档运行一个月以及新增/关闭岗位的实际验证。

完整验收仍以 docs/10-in-game-acceptance.md 为准。`in_game_tests_passed` 继续为false；六个月冒烟测试单独记录为用户实测，不等同于所有功能通过。


0.3.2按用户要求将灰蚊人四翼改为贴背收拢，白、灰各增加一个摘盔肖像（_02）。摘盔面部为本Mod暂定设计，尚无核实的官方面孔参考。创建/编辑帝国时在海帕姆肖像组选择；预设仍默认戴盔（_01）。旧存档保持现有戴盔选择，重启后灰蚊人同一肖像编号会显示收翼贴图。没有加入自动摘戴头盔动画。游戏内可选项与显示待实测。
