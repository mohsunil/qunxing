# 舰队、贸易与母星舰造工程

## 舰团化

重要社会学科技：压低单舰队规模、显著提高帝国海军容量、极低舰队消耗。可参考佣兵城邦的组织体验，但用户没有要求实际创建佣兵租赁国家。

单舰队指挥上限与帝国海军容量占用要分别验证。同级舰船容量更小，当前暂按海军容量占用降低理解；若同时降低指挥占用，必须检查是否抵消小舰团限制。所有精确百分比为草案。

## 等离子轴炮与轴炮舰

小型、中型、重型轴炮是一条高威力专属科技路线。物理学归属、S/M/L槽位映射、重型独立舰艏均为助手提案，需与目标版本实际槽位和模型挂点衔接。

轴炮舰核心要求：合金为主、高船体、高攻击、几乎无护盾。建造与维护均偏合金是当前解释，需要在平衡表明确。舰团化降低总体维护，但不应把维护资源类型悄悄改回普通船。

具体建造成本、命中、追踪、射程、射界、护甲、能耗、维护、海军容量与指挥占用都尚未实测。不要将T-34类比当成历史性能数据，也不要用外观模型替代舰体规则。

## 邮政舰队

社会学科技；大量贸易与少量旧船补充。邮政舰队为海帕姆帝国内部体系。助手提出的50%贸易、3—5年刷新、邮政港、旧船翻新与拆解不是用户已批准的精确规则。

旧船应明确归属、装备和升级方式，计入海军容量及维护。避免通过读档、多个港口或反复建拆无限触发事件。需要是否自动归队与事件通知设置。

## 海帕姆星舰造工程

用户要求参考环形世界基址的工程形式，逐步把母星变成巨大战舰工厂。建议采用地表改造与轨道船坞联动，保留母星人口和核心建筑；这是推荐实现方式，最终需确认。

工作阶段名：工程基址 → 行星军工体系 → 环星装配船坞 → 舰造世界。阶段名称和数值非正式世界观。

必须具有实际造舰队列、并行生产和舰队补充；不能只添加行星修正或自动刷船后声称总船厂完成。应测试舰船设计器、装备升级、维修、补舰、队列与多星球所有权变化。

用户的强势节奏要求中期已有作战工业基础，后期才达到惊人爆兵。不要把面对大可汗的全部强度锁在最终巨构后。
