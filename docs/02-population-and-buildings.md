# 人口与建筑规格

## 皇家孵化场

核心：类似机械工厂的生物人口生产设施，兼具医疗／基因治疗所式功能和社会学研究。母星开局已有孵化场属于此前助手建议，尚不是用户明确锁定的开局配置。

灰蚊人孵化由岗位需求驱动，而非无条件自然增长。有效需求指已启用的实际非精英生产、服务、科研或军事岗位。失业状态、犯罪岗位、待命占位不得反过来制造孵化需求。

补员目标先扣除当前可用于工作的灰蚊人与其他人口已实际占用的岗位，再扣除未完成孵化订单；计算应基于目标版本的真实劳动力机制，不能把旧版单个人口与新版人口组硬套成一比一。

### 状态变化

| 情况 | 目标行为 |
|---|---|
| 孵化场完成，已有非精英缺口 | 为缺口安排3—6个月补员 |
| 新岗位出现 | 新增缺口独立计时，不重置旧批次 |
| 现有岗位满员 | 停止孵化 |
| 出生前岗位需求下降 | 缩减或取消订单 |
| 岗位减少，灰蚊人过剩 | 移除过剩灰蚊人口 |
| 基因改造产生灰蚊人亚种 | 仍归属灰蚊人谱系与相同规则 |
| 星球易主或孵化场停用 | 订单归属与清理行为需要版本实测 |

不要通过跨星迁移、闲置储备岗位来替代过剩人口移除。不要误删白蚊人或灵蚊人。孵化停止后的删减规则是否仍保持是一个待确认细节，见未决事项。

灰蚊人的常规自然增长应被控制到不会绕过岗位规则；精确规则需与基因改造、迁入、事件人口、占领和工作效率变化一起测试。

## 非精英专家岗位

协同进化原版副种族特质可能限制专家就业，不能仅修改说明文本后声称所有非精英岗位都能填满。需定制灰蚊人特质／就业权限，核对行星特化、工业、科研、医疗、士兵岗位及自动分配。玩家指定的实际行为优先于原版起源默认副种族限制。

## 快速基因改造

保留独立灰蚊人用途模板与亚种识别；极快改造是定案方向，90%减时只是助手草案。新孵化人口继承所选模板属于建议，应在实现前明确界面与自动选择方式。

## 反应釜

减少本星球全部灰蚊人的食物维护，包括改造亚种。50%／升级75%均未定案。是否每星球唯一、是否有升级、消耗什么资源，以及同类建筑如何叠加，需要确定。测试时应展示实际食物消耗变化。

## 军耀殿

政治方向首都建筑，大量凝聚力，领袖寿命无限。按不因年龄死亡设计；战斗／剧情死亡处理、效果是否永久、建筑失效后如何处理需明确。首都专属建筑还是替代首府主楼，需要用户确认，当前先不破坏原首府结构。

## 皇家设计局

大量产出物理学和工程学。需要明确岗位与建筑直接产出的比例、等级与维护。任何科研岗位都必须满足最新非精英灰蚊人就业要求。

## 重力子神殿

灵蚊人相关建筑，凝聚力与贸易双高产出，解锁灵蚊人陆军与事件。灵蚊人解锁科技、人口来源、增长和过剩处理不自动继承灰蚊人规则。神殿缺失条件会影响边疆事件，需统一国家级判定。
