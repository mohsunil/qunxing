# 0.5.1：救国会与可见资源母星

用户确认：海帕姆救国会属于危机改革派，缺粮或战败后要求整顿帝国。以下阈值、诉求奖励与经费是原型数值。

连续三个月粮食低于200或发生粮食短缺，或成为战败方后的十年内，每月10%机会开放救国会。成立仍需满足原版成员条件；正常和平、粮食充足时不会凭空成立。成员和领袖限定白蚊人谱系，不改变灰蚊人的受控人口机制。

诉求：粮食储备至少1000且没有短缺；走出战败恢复期；运行皇家设计局；执行救国整顿。派系行动花费1000能量与500凝聚力，五年内农业岗位产出+25%、稳定度+5。凝聚力收入采用原版派系规则。不会自动更改帝国伦理、政体或发动内战。界面借用威权政治图标，成员允许各类伦理。

母星现有四项专属地貌在真实存档中存在，但用户反馈资源优势不明显。现将原有数值合并到可见的“海帕姆：资源母星”图标：总区划+12、采矿上限+12、发电与农业上限各+10、矿物岗位+100%、能源和食物岗位各+75%。地貌不再重复提供这些数值；稀有元素依然需要开采科技及就业人口，修正触发块格式已按本机接口整理。已有母星在重载后的月度检查自动补上图标，不需要重开。

0.5.0实测：新局初始化日志已执行；新存档中灰蚊人仅余1300工人和400专家，没有闲置灰蚊人，白蚊人保留。最初13名所属领袖均为白蚊人。此为具体存档快照，不证明所有未来事件领袖或复杂岗位转换均通过。

检查：原有406组人口算法、22组边疆控制流、双飞升24组、救国会102组和资源双重加成防护通过。新增派系命名、成员吸引、诉求、行动及资源图标仍需真实引擎和游戏界面验证。舰体仍是原创低模初版，尺度、材质、炮口与战斗未验收。银心定位与动态嘴部尚待完成。
