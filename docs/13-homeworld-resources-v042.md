# 0.4.2：母星资源富集与引擎修复

用户确认海帕姆母星需要大量资源。旧初始化只额外加入三处普通资源地貌，本版改为四处海帕姆专属资源地貌，保留母星自然生成的其他资源与障碍。

| 母星地貌 | 区域上限增量 | 实际生产效果 |
| --- | --- | --- |
| 深层富矿 | 采矿+12；全星球总区域+12 | 矿物岗位产出+100% |
| 行星能源脉络 | 发电+10 | 能量岗位产出+75% |
| 原生营养海 | 农业+10 | 食物岗位产出+75% |
| 稀有元素共生层 | 无 | 研究对应开采科技后，矿工附产水晶、农业岗位附产天然气、技工附产微粒 |

区划上限不等于已建区划。区域和岗位仍需建设、就业与维护；没有每月事件赠送资源，没有直接添加合金。三项稀有资源均使用4.5.2原生岗位附产修正，原型附产系数各0.05，实际产量受劳动力和修正影响，待游戏核对。

所有数值均为初始平衡提案，不是用户指定数字。只作用于开局登记的海帕姆母星；迁都不把加成复制到新首都，也不会给所有殖民地添加。每次添加都检查对应地貌是否已经存在，月度迁移不会重复堆叠。旧版额外加入的普通地貌保留，以免移除自然生成的同名资源。

新局初始化即添加四处地貌。已有海帕姆存档重启游戏加载新版后，下一个月度脉冲为原母星补齐缺少的地貌；首次迁移非常早的旧存档仍按既有母星登记规则处理。运行中的进程不会自动加载新事件定义，更新文件后需保存并重新启动游戏。

四处地貌暂引用原版对应资源图标，未复制或发布原版图片。后续可替换成独立地质景观图。

## 继承的0.4.1实际引擎修复

- 4.5.2瞬发武器不接受脚本内cooldown；轴炮数值改由安装器生成本地weapon_components.csv适配，保留原有全部行再追加三条自有武器数据。只发布design/axial-weapon-stats.json和生成程序，绝不打包本地生成的原版数据。
- 舰团化造舰速度使用starbase_shipyard_build_speed_mult。
- 邮政修复费用用has_resource判断。
- 补充舰造巨构详情、四个总览图标及新船型修正的本地化。
- 实际创建帝国时，引擎提前尝试生成暂不可造舰型的设计，报必需反应堆和推进器不可用。本版取消这些基础必需组件的科技门槛，船体和轴炮武器仍保留科技条件。仅这些自有船型可用这些组件；修正后待实际重测。

0.4.1日志确实读取了海帕姆定义并开始生成海帕姆新战役；尚不能据此声称人口机制、母星加成或战斗表现验收通过。本版通过结构与本机依赖检查，游戏内资源增量、岗位产出、旧存档迁移及新战役自动设计均待验收。
