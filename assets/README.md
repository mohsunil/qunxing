# 视觉资源

活动肖像为 `portraits/` 中正常成年比例的白、灰蚊人半身PNG，经 `scripts/build_visual_assets.py` 导出为游戏DDS。用户明确否决Q版头像，脚本不会回退Q版。`source/` 的Q版原图仅保留作盔徽、头盔身份与旗色参考。

正常比例主要参考来自本地“视频用”资源：荣耀卫兵、带虫翼长生军三视图。通过内置image_gen改编，精确保留阵营身份并校正灰蚊人为四翼。完整提示词见 `generation-prompts.md`；来源与哈希见 `visual-assets.json`；`previews/` 为游戏尺寸预览。

这些是静态肖像，没有动画模型。游戏内显示及旧存档迁移仍待验收。舰船外链只供后续参考，未作为本版已制作内容。


0.3.2按用户要求将灰蚊人四翼改为贴背收拢，白、灰各增加一个摘盔肖像（_02）。摘盔面部为本Mod暂定设计，尚无核实的官方面孔参考。创建/编辑帝国时在海帕姆肖像组选择；预设仍默认戴盔（_01）。旧存档保持现有戴盔选择，重启后灰蚊人同一肖像编号会显示收翼贴图。没有加入自动摘戴头盔动画。游戏内可选项与显示待实测。
