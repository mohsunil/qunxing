# 海帕姆：银心初航｜Stellaris Mod 开发工程

版本：0.4.0-alpha。目标：本机 Stellaris Cygnus 4.5.2 (9776)。

这是正在制作的游戏原型。本版新增内容已通过结构、资源引用和本机定义依赖检查，尚未完成引擎加载与战役验收。此前六个月测试属于旧版，不能用来证明本版新增系统有效。

## 本版内容

- 协同进化双种族、白蚊人领袖限制、灰蚊人按岗位缺口孵化及过剩删除、皇家孵化场和反应釜。
- 皇家生物工程与30天灰蚊人模板程序、军耀殿首都决议与领袖续生、皇家设计局。
- 灵能理论首次觉醒灵蚊人、重力子神殿、灵蚊人卫队与两组神殿事件。
- 舰团化、三档等离子轴炮、三种低容量轴炮舰、六个舰段及专用反应堆／推进器／火控。
- 邮政贸易加成、邮政枢纽与旧船回收选择。
- 母星专用四阶段舰造工程，保留居民与地表，逐步扩建造舰生产线。
- 八张成年比例角色肖像、用户提供的种族标识、六张原创建筑图片、十一张科技图标、五张建筑事件卡。

白蚊人当前不加头须，按用户最新要求留待自行添加；白蚊人无翼，灰蚊人四翼贴背收拢。肖像仍为静态贴图，接入原版节肢类问候音引用，尚未试听。舰船及舰造巨构仍引用原版三维外观，未制作专属模型。

## 还没完成

银心附近的固定开局、边疆自动扩张和殖民、组织度与友好分裂、借粮／饿殍遍地／钢铁蚊人联军、原版基因与灵能双飞升兼容，以及嘴部动画。王家双螺旋科技目前只提供生物特质点数，不代表原版双飞升已经开放。

所有平衡数值均为原型；3—6个月补员、白蚊人领袖与灰蚊人过剩删除是用户固定要求。尚未验证迎战大可汗的实战能力、后期生产性能或本版人口修复结果。

## 制作与测试

详细进度见 docs/12-gameplay-expansion-v040.md；原始32条需求保存在 design/requirements.json，作为最初设计合同，功能状态以最新进度文件为准。

```powershell
python scripts/validate_mod.py
python scripts/validate_content.py --game "D:\steam\steamapps\common\Stellaris"
python scripts/package_handoff.py
python scripts/install_mod.py --game "D:\steam\steamapps\common\Stellaris" --userdir "$env:USERPROFILE\Documents\Paradox Interactive\Stellaris"
```

安装器只更新海帕姆模组，备份本模组旧文件，生成本地规则适配，不修改游戏原文件、其他模组、播放集和存档。原版规则适配文件、原始日志、存档和本机安装报告不进入公开包。

GitHub目标为用户已授权的公开仓库 mohsunil/qunxing。云端环境未创建或发布；上传提交和完整性验证以工程目录外的交付报告为准。
